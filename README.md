# Udemy Clone Website

## About the Project

This is my second web development project, inspired by the Udemy online learning platform. I created this website using HTML and CSS as part of my Full Stack Web Development learning journey.

The website displays recommended courses, popular courses, course categories, recommended topics, and a promotional banner.

## Features

- Navigation bar with a search field
- Course categories with hover effects
- Promotional banner image
- Recommended courses with ratings and prices
- Recommended topics section
- Popular courses section
- Footer with website-related links
- Flexible layouts using CSS Flexbox

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Font Awesome
- Google Fonts

## What I Learned

Through this project, I practised creating website layouts using Flexbox, arranging course cards, styling navigation elements, implementing hover effects, and organizing content into different sections.

## Future Improvements

- Make the website responsive for mobile devices.
- Add functional search and navigation.
- Add interactive features using JavaScript.

## Project Purpose

This project was created for learning and practice purposes to improve my frontend development skills.
